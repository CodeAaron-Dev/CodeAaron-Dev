## Projetos

### Oryx

Plataforma de inteligência conversacional para times comerciais, construída para o Challenge FIAP
2026 com a TOTVS. Recebe transcrições de reuniões de vendas e identifica onde a conversa travou,
por quê, e o quanto se pode confiar nessa leitura. Spring Boot com Java 21, JPA e PostgreSQL.

A parte que mais me ensinou foi a medição. O gerador de dataset sintético, em Python, parte as
formulações de cada tipo de fricção em um inventário visível e um oculto — quem escreve o detector
só pode ler o visível, e o recall que conta é o calculado sobre o conjunto oculto. É o que separa
generalizar de decorar. O gerador ainda gradua a intensidade de cada objeção e inclui controles
negativos e trechos ambíguos como ruído.

Repositório privado.
